# ExPanel

ExPanel is a Windows desktop application for financial businesses that handle currency exchange. It helps staff keep customer and transaction records, issue invoices, and prepare reports for FINTRAC, Canada's financial intelligence agency.

## An exchange at the counter

When a customer exchanges currency, staff can record the customer and transaction details, then use the exchange rate to calculate the invoice total. The invoice can include a FINTRAC submission code so staff can cross-reference the receipt with the report later.

## Beyond the transaction

- **Customer screening.** Staff can check customers against sanctions and politically exposed person (PEP) lists through the screening service.
- **Reporting and review.** Staff can retrieve past reports and customer records when reviewing a transaction or preparing a filing.
- **Office controls.** Administrators can assign access by employee role and use the activity log to review changes to office data.

The desktop application keeps office records on the local network. External screening is available through an API.
